## 解析口径

已签名 extrinsic 按精确结构解析，不用扫描调用头（扫描会在签名区误命中 `[04][00]`，
产生数百亿元的假金额与空备注）。布局：

```
compact 长度前缀 → version(0x84) → MultiAddress(0x00 + 32B)
  → MultiSignature(类型 1B + 64B，ecdsa 为 65B)
  → era(1~2B) → nonce(compact) → tip(compact)
  → CheckMetadataHash mode(1B)  ← 易漏，漏掉会导致 pallet/call 偏移错位
  → call: [pallet][call][args…]
```

`transfer_with_remark`(4/0) 参数：`[收款账户 32B][金额 u128 LE，单位分][备注 BoundedVec<u8>]`。
