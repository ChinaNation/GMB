## 实施边界

- 只改造 App 自有页面内容，不修改底部导航图标、顺序、标签或业务路由。
- 不修改 `citizenapp/lib/8964/` 广场实现。
- 不新增业务入口、字段、权限、接口或假数据。
- 连接状态必须来自 `LightClientStatusSnapshot` 与真实读取错误，不以固定文案伪造。
- 现有业务动作、状态机、钱包签名、聊天同步、提案数据源和身份读取保持不变。
- 不保留本轮被取代的旧布局或双轨样式。

## 预计修改目录

- `citizenapp/lib/my/user/`：实现“我的”页面照片头部、资料区、紧凑主入口和个人服务分组。
- `citizenapp/lib/transaction/`：实现交易页顶部、连接状态、快捷入口和支付表单布局。
- `citizenapp/lib/chat/`：实现聊天页标题、搜索和统一会话列表视觉。
- `citizenapp/lib/citizen/`：实现公民页五段导航和提案列表视觉层级。
- `citizenapp/lib/ui/widgets/`：为交易页提供三态紧凑连接状态展示，默认行为不影响其他页面。
- `citizenapp/test/`：更新现有页面和连接状态组件测试，不新建测试文件。
- `memory/`：更新 CitizenApp 技术文档、任务状态和验收记录。
