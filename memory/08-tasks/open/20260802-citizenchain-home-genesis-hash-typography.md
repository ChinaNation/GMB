# 区块链软件首页创世哈希与字体层级

状态：已完成（本地尚未提交、未推送）

## 任务目标

- 首页“身份”区域依次显示节点角色、节点地址和创世哈希。
- 创世哈希必须来自本节点 `chain_getBlockHash(0)` 的既有缓存，不得硬编码。
- “P2P地址”界面文案统一改为“节点地址”，内部 `peer_id` 官方命名保持不变。
- 节点角色、创世哈希、节点地址的键和值建立明确字体层级。
- 首页“区块、身份、发行”三个标题增大，且样式不得影响其它页面。
- 首页区块区的 `finalizedHeight` 界面文案统一显示为“最终高度”。
- 右侧交易面板的备注字节计数保持在输入框外部下方，并与输入框右边缘对齐。
