## 第 1 项实施结果

- 会员页、广场发布前检查与 Worker 发布门禁现在统一收敛到“finalized 链上订阅 → D1 权益
  镜像”；App 不自报会员，Worker 是发布授权真源。
- 5 分钟 Cron 保留后台到期候选对账；发布拒绝路径负责补建漏确认或陈旧的单 CID 镜像，
  两条路径复用同一平台状态写入函数。
- Worker 只有在 finalized 链确认无有效会员后返回 402；链 RPC、原子写入或复核后镜像仍
  无法放行时返回可重试 503。App 已按 401/402/503 分别显示登录、会员和验证失败提示。

## 第 2 步实施结果：第 3 项广场与用户主页首次加载

  媒体 Session。Worker 明确返回 401 时清除当前身份账户 Session 并只重新握手一次。

  当前 Tab 自动补远端；他人页面不读取本机副本，也不再产生必然失败的匿名请求。
- `ProfilePostsTab.didUpdateWidget` 已覆盖 Session、CID、分类、内容形态和媒体过滤变化，统一
  重置分页；加载代际丢弃旧响应。401 委托父页刷新一次 Session，空态/失败态支持下拉重试，
  确认无钱包时显示明确提示。
