# CitizenConsole 发币控制台查看与布局统一

## 任务目标

1. 已配置的发币地址与 `SETTLE_TOKEN` 补齐「查看」操作，其余已有查看逻辑保持一致。
2. 订单台账右侧按上下两行放置解锁状态和解锁/锁定按钮。
3. 页面统一使用「发币控制台」「订单台账」「配置列表」。

## 安全边界

- 所有查看动作逐次要求 Touch ID，不复用发币控制台的持续解锁状态。
- `SETTLE_TOKEN` 只允许在本机页面行内短时显示，不写日志、不缓存、不落盘。
- 发币地址只由原生安全进程读取发币私钥并派生；普通 Node 和浏览器只能取得公开地址。
- 发币私钥 `DISBURSE_KEY` 永不返回普通 Node、浏览器或日志。
- 不改变持续解锁、锁定、订单结算、发币、订阅或 runtime 逻辑。
- 不推送 GitHub，不触发远端 CI。
