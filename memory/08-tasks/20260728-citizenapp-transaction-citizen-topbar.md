1. 交易页删除顶部“交易”标题，将真实公民链呼吸状态与“最终区块 N”移入原标题区域。
2. 交易页删除原链状态卡片、卡片背景及状态与最终区块之间的竖线；扫一扫/多签账户卡片及其中竖线保持不变。

6. CitizenApp 其他页面不得再显示任何链连接状态条或状态卡片；链状态后台读取、交易
   门禁和失败原因仍保留，唯一可见的全局链状态只在交易 Tab 顶栏。

## 唯一目标状态

- 交易页顶栏继续保留左侧通讯录和右侧交易钱包入口。
- 顶栏中央仅显示“呼吸灯 + 公民链 + 最终区块号”，不使用卡片、边框、竖线、状态文字
  或额外加载图标。
- 状态仍由真实 `LightClientStatusSnapshot` 与读取错误驱动，但仅通过整组颜色表达：
  - 绿色：链状态可用；
  - 蓝色：正在初始化、连接或同步；
  - 红色：真实状态读取失败。
- 最终区块号只读取 `currentVerifiedFinalizedBlockNumber`；尚无已验证最终区块时显示“—”，不得用 best/latest 区块替代。
- 呼吸灯、“公民链”和“最终区块 N”使用完全一致的状态色。
- “公民链”和“最终区块 N”使用左右等宽区域，两者间固定空隙的中心点严格落在屏幕
  水平中心；呼吸灯跟随“公民链”位于左侧区域。
- 其他页面只保留不可见的链状态读取与操作门禁，不显示连接状态组件。
- 下拉刷新继续重载钱包、交易记录并触发轻节点状态重探。
- 独立“链上支付”页面保持原标题，删除内容区链状态卡片，只保留后台状态读取。
- 公民页子 Tab 保持原顺序、样式、交互和 SafeArea，仅删除标题并上移整体位置。
